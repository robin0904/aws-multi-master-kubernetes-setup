## 2. EXECUTION FLOW (Step by Step)

```
START HERE (Your Local Machine)
│
├─► 1. Install Tools (one-time)
│   └─► terraform, ansible, awscli, jq
│       Duration: 10 minutes
│       Where: Your machine
│
├─► 2. Configure AWS Credentials (one-time)
│   └─► aws configure
│       Duration: 5 minutes
│       Where: ~/.aws/credentials
│
├─► 3. Generate SSH Key (one-time)
│   └─► ssh-keygen -t ed25519
│       Duration: 1 minute
│       Where: ~/.ssh/id_ed25519
│
├─► 4. Run Terraform Apply (each deployment)
│   └─► terraform apply
│       Duration: 5 minutes
│       Where: AWS (provisions 7 EC2 instances)
│       Output: IPs of all nodes
│
├─► 5. Export Terraform Outputs
│   └─► terraform output -json > inventory/tf_outputs.json
│       Duration: <1 minute
│       Where: Your local filesystem
│
├─► 6. Generate Ansible Inventory
│   └─► bash inventory/generate-inventory.sh
│       Duration: <1 minute
│       Where: Your local filesystem
│
└─► 7. Run Ansible Playbooks (each bootstrap)
    │
    ├─ playbook 01: Common OS Setup (5-10 min)
    │  └─ Ansible → SSH to each node → Configure OS
    │
    ├─ playbook 02: HAProxy Setup (2-3 min)
    │  └─ Ansible → SSH to HAProxy node → Configure load balancer
    │
    ├─ playbook 03: K8s Install (5-10 min)
    │  └─ Ansible → SSH to all nodes → Install container + K8s
    │
    ├─ playbook 04: Cluster Init (5-15 min)
    │  └─ Ansible → SSH to master-1 → kubeadm init + Calico
    │
    └─ playbook 05: Join Nodes (10-15 min)
       └─ Ansible → SSH to all other nodes → Join cluster

FINISH: Kubernetes cluster running, all nodes Ready

Total Time: 40-60 minutes
```

## 3. HOW ANSIBLE CONNECTS (SSH Flow)

```
Your Local Machine (running ansible-playbook)
│
├─ Ansible reads: inventory/hosts.yml
│  │
│  ├─ master-1: 10.0.10.10  (private IP)
│  ├─ master-2: 10.0.10.11  (private IP)
│  ├─ worker-1: 10.0.11.10  (private IP)
│  └─ bastion: 10.0.1.x     (public IP)
│
├─ If bastion enabled:
│  │
│  └─► SSH Connection Path:
│      Your Machine
│         ↓ (public internet)
│      AWS Bastion (10.0.1.x)
│         ↓ (private network)
│      Master/Worker (10.0.10.x / 10.0.11.x)
│
├─ If bastion disabled:
│  │
│  └─► Ansible uses:
│      ansible_connection: local (for bastion)
│      ProxyCommand: SSH through bastion
│
└─ On Each Node:
   │
   ├─ SSH connects as: ec2-user
   ├─ Uses key: ~/.ssh/id_ed25519
   ├─ Runs with sudo: ansible_become: yes
   ├─ Root access: ansible_become_method: sudo
   │
   └─► Runs Tasks:
       • Install packages (yum)
       • Configure kernel
       • Start services
       • Wait for status
       All output sent back to your terminal
```

```

│   └─► CREATES everything in AWS

└─► $ terraform output -json > inventory/tf_outputs.json

        • master_private_ips (list)
        • worker_private_ips (list)

```

## 5. ANSIBLE ROLES & TASKS FLOW

```
Your Machine: $ ansible-playbook playbooks/site.yml

│
├─► PLAY 1: Common OS Setup (01-common.yml)
│   Hosts: all (every node)
│   Tasks:
│   ├─ Update packages
│   ├─ Disable SELinux
│   ├─ Disable swap
│   ├─ Load kernel modules
│   ├─ Configure sysctl
│   ├─ Disable firewall
│   └─ Reboot nodes
│   Duration: 5-10 minutes
│
├─► PLAY 2: HAProxy Setup (02-haproxy.yml)
│   Hosts: haproxy (single node)
│   Tasks:
│   ├─ Install HAProxy
│   ├─ Render config from template
│   ├─ Start service
│   └─ Verify listening on 6443
│   Duration: 2-3 minutes
│
├─► PLAY 3: Kubernetes Install (03-k8s-install.yml)
│   Hosts: k8s_nodes (all nodes except bastion)
│   Tasks:
│   ├─ Add Kubernetes repo
│   ├─ Install containerd
│   ├─ Install runc
│   ├─ Install CNI plugins
│   ├─ Install kubeadm, kubelet, kubectl
│   └─ Configure systemd cgroup driver
│   Duration: 5-10 minutes
│
├─► PLAY 4: Cluster Init (04-cluster-init.yml)
│   Hosts: masters (all 3, but only master-1 initializes)
│   Conditional: when: is_first_master == true
│   Tasks:
│   ├─ kubeadm init (master-1 only)
│   ├─ Wait for API server
│   ├─ Install Calico CNI
│   ├─ Fetch kubeconfig
│   └─ Verify cluster Ready
│   Duration: 5-15 minutes
│
└─► PLAY 5: Join Nodes (05-cluster-join.yml)
    Hosts: k8s_nodes (but not master-1)
    Serial: 2 (run 2 nodes at a time)
    Tasks:
    ├─ Get join token from master-1
    ├─ For additional masters:
    │  ├─ Join with certificate key
    │  └─ Wait for node Ready
    └─ For workers:
       ├─ Join with bootstrap token
       └─ Wait for node Ready
    Duration: 10-15 minutes

RESULT:
✅ All 5 nodes Ready
✅ All system pods Running
✅ etcd cluster healthy
✅ Kubernetes API responsive
```

## Quick Summary

**Question**: Where does Ansible run?  
**Answer**: YOUR LOCAL MACHINE (same place as Terraform)

**Question**: Do EC2 nodes need Ansible?  
**Answer**: NO. Ansible connects via SSH and configures them.

**Question**: Do EC2 nodes need Terraform?  
**Answer**: NO. Terraform is only for provisioning.

**Question**: What if I lose my SSH key?  
**Answer**: You'll need to terminate EC2 instances and create new SSH key.

**Question**: Can I run this from a server instead of my laptop?  
**Answer**: YES. Just install tools on that server instead.

**Question**: Can I use AWS Bastion as Ansible machine?  
**Answer**: YES. SSH to bastion and run Ansible there.
        But recommended to run from your local machine.
